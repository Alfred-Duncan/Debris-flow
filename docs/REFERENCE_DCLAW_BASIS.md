## Chosen baseline and why

The baseline transfers the Mount Baker material state and the middle published permeability (`1e-11 m2`), because it is the central value of the study’s explicitly published three-value range. The current D-Claw qinit pattern is used because Jilong has no public downstream-entry hydrograph and a stationary raster mass does not silently impose a velocity or a custom boundary state. `mref=0.60`, `alpha_c=0.05`, `delta=0.01`, `c1=1`, and `sigma0=1000 Pa` are documented current D-Claw/Mt Tanh implementation settings; they are labelled implementation controls, not Jilong measurements.

The baseline does **not** turn on entrainment: the event evidence supports progressive entrainment qualitatively, but no defensible spatial thickness, entrainment rate, or entrained material fraction is publicly established for the modelled reach. Inventing those fields would be less defensible than an explicitly source-volume-controlled scenario.
