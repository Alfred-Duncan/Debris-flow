# Jilong reference-based D-Claw case

This is an independent engineering scenario generator. It neither modifies nor depends on the archived `jilong_baseline`, `jilong_event_reconstruction`, `jilong_event_v2`, or `jilong_event_v3` cases.

## Reference transfer

The primary practice reference is the USGS Mount Baker long-runout lahar study (SIR 2024-5133). Its material configuration and published permeability range are used here. The input construction follows the current official D-Claw qinit examples: a stationary initial mass is specified through `h` and `hm`, with no imposed source velocity or custom boundary condition. Because the Jilong source state at downstream model entry is unmeasured, the 1 Mm3 baseline is the smallest published Mount Baker magnitude and is explicitly a scenario control, not an event inversion.

The baseline is 64 m, fixed-grid, 600 s, with 10 s output. It uses `m0=0.62`, `mcrit=0.64`, `kref=1e-11 m2`, `rho_f=1100 kg/m3`, `rho_s=2700 kg/m3`, `mu=0.005 Pa s`, `phi=38 degrees`, hydrostatic initial pressure, and no entrainment field because no spatial erodible-thickness constraint has been published for this corridor.

## Reproducible sequence

```bash
export CLAW=/root/src/clawpack
export JILONG_DATA_ROOT=/path/to/downloaded/data/extracted  # only if data are outside this Git clone
python terrain_preprocess.py       # creates TT3 and hard-gates on TERRAIN_CHECK.md
python run_batch.py               # executes baseline then only its conditional planned branch
```

`run_batch.py` writes compact summaries and one diagnostic figure. Solver fields remain under `runs/*/_output` and are deliberately not versioned. The committed inputs are regenerated by `terrain_preprocess.py` and `source_inputs.py`.

## Terrain invariant

Rasterio's destination raster has physical rows ordered north-to-south. The script reprojects the native 8-m DEM first and uses the 12.5-m DEM only where the 8-m raster has nodata; it reverses the resulting array only when assigning GeoClaw `Topography.Z`, whose `y` coordinates increase south-to-north. It then reads the written TT3 back and compares it with the original observed DEM composite at required fixed sites and 100 seeded random valid points. Any failed check stops before a solver run.
