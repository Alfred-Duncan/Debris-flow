# Jilong D-Claw baseline

This is one provisional, uncalibrated downstream-propagation case.  It uses a 64 m fixed grid in EPSG:32645, a DEM primarily built from the downloaded 8 m DEM, and the D-Claw-native `qinit` thickness field for one stationary initial debris mass at the mapped main-river entry.  The 12.5 m DEM fills only 8 m no-data cells.

It is deliberately not a reconstruction or calibration of the 2026 event.
